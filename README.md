# Prototype billetterie Solisport

Prototype cliquable de l'application Solisport : choix d'un sportif à soutenir, réservation d'une sortie (match, kayak, escape game, rencontre), paiement, billet, suivi de l'impact et récompenses.

Fichier unique et autonome : ouvrir `index.html` dans un navigateur.
